## Matrix Homeservers, SDKs, Bots, and Bridges

- https://github.com/matrix-construct/tuwunel
    - Official successor to conduwuit (Matrix homeserver)
- https://github.com/maelstrom-rs/maelstrom
    - The Matrix homeserver for serious scale - clusterable, highly available, horizontally scalable
- https://github.com/timokoesters/conduit
    - A simple, fast and reliable Matrix server (mirror, see conduit.rs)
- https://github.com/matrix-org/matrix-rust-sdk
    - Matrix Client-Server SDK for Rust
- https://github.com/Lolappa/Telegram-Matrix-Bridge
    - Bridges messages between Telegram and Matrix
- https://github.com/msrd0/tg2mx_bot
    - Bot to import Telegram sticker packs to Matrix (MSC2545 Ponies stickers) for FluffyChat, Nheko, Cinny etc
- https://github.com/ultram4rine/alerter
    - Telegram and Matrix bot for alerts from Alertmanager
- https://github.com/LuckyTurtleDev/mstickereditor
    - Imports sticker packs from Telegram for use with the Maunium sticker picker for Matrix
- https://github.com/hexagonal-sun/llamatrix
    - An Ollama Matrix bridge bot
- https://github.com/jpypi/rustix
    - Matrix chat bot written in Rust
- https://github.com/turboflakes/crunch
    - CLI and Matrix bot to claim staking rewards every Era for Substrate-based chains
- https://github.com/sparky8251/anansi
    - Simple multipurpose project-focused Matrix bot
- https://github.com/etkecc/baibot
    - A Matrix bot for using AI capabilities (text-generation, TTS, STT, image-generation, etc.)
- https://github.com/bnjbvr/trinity
    - Matrix bots in Rust and WebAssembly
- https://github.com/cyb3rko/awesome-matrix-bots
    - A list of Matrix bots, bridges and related things

- https://github.com/telegram-rs/telegram-bot
    - Rust library for creating a Telegram Bot

- https://github.com/teloxide/teloxide
    - An elegant Telegram bots framework for Rust

- https://github.com/AyuGram/AyuGramDesktop
    - Desktop Telegram client with good customization and Ghost mode
