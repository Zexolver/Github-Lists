## Generic Rust Chat Apps/Servers (not Discord/Matrix/XMPP/Telegram-official)
#### Interesting pattern: every one of these found so far is a TUI (terminal client), not a GUI app.

- https://github.com/ByteMaster2003/null-talk
    - High-performance, E2EE chat application. Ratatui TUI client + a scalable server, stress-tested to 100K+ concurrent connections
    - Interface: TUI
- https://github.com/Paol0B/Rchat
    - Modern chat system in Rust with complete end-to-end encryption, asynchronous client-server architecture
    - Interface: TUI
- https://github.com/PabloLec/sb_websocket_rust
    - WebSocket TUI chat server and client in Rust
    - Interface: TUI
- https://github.com/d-holguin/chat-tea
    - A Rust-based chat app with an async server-client setup using Tokio
    - Interface: TUI (built with ratatui)
- https://github.com/Yengas/rust-chat-server
    - Room based Chat Server and TUI implementation in Rust
    - Interface: TUI
- https://github.com/xaerru/chatui
    - Chat app made using the standard library net module and tui-rs
    - Interface: TUI
- https://github.com/FedericoBruzzone/tgt
    - TUI for Telegram written in Rust
    - Interface: TUI

- https://github.com/fluxerapp/fluxer
    - A free and open source instant messaging and VoIP chat app for friends, groups, and communities
    - Interface: GUI

- https://github.com/osa1/tiny
    - A terminal IRC client
    - Interface: TUI

- https://github.com/michael-grunder/gitchat-relay-server
    - Toy E2E encrypted chat app
    - Interface: TUI/CLI

- https://github.com/m0veax/mumbleping-rs
    - Library to send a ping to a Mumble instance
- https://github.com/RandyMcMillan/mumble-rs
    - Rust bindings/tooling for Mumble
- https://github.com/SpaceManiac/mumble-link-rs
    - A Rust library for using Mumble's Link plugin for positional audio
- https://github.com/mumble-voip/mumble
    - Mumble - an open-source, low-latency, high quality voice chat software

- https://github.com/Blightmud/Blightmud
    - A terminal MUD client written in Rust
