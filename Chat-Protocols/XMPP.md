## XMPP Servers, Clients, and Libraries

- https://github.com/mdm/confidante
    - A Rust XMPP server
- https://github.com/hmzdot/mini-xmpp
    - A toy implementation of the XMPP messaging protocol
- https://github.com/prose-im/prose-core-client
    - Prose core XMPP client manager & protocols
- https://github.com/paulfariello/aparte
    - Simple XMPP console client written in Rust, inspired by Profanity
- https://github.com/Florob/rust-xmpp
    - Simple XMPP library in Rust
- https://github.com/qecu/akama
    - An XMPP client written in Rust
