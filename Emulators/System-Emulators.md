## System/CPU Emulators (general, non-Minecraft/browser)

- https://github.com/takahirox/riscv-rust
    - RISC-V processor emulator written in Rust, compiled to WebAssembly
    - Runs in a web browser via WASM - no separate desktop build needed
- https://github.com/d0iasm/rvemu
    - RISC-V emulator for CLI and Web, written in Rust with WebAssembly. Supports booting xv6 (a teaching OS) and Linux (ongoing/WIP)
    - Has both a native CLI build and a web/WASM build
- https://github.com/libraries/gameboy
    - Full-featured, cross-platform GameBoy emulator written in Rust
