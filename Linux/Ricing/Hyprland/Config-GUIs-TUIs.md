## A list of Hyprland Config GUIs/TUIs

- https://github.com/MarkusVolk/hyprgui
    - GUI for editing/managing your Hyprland config
- https://github.com/timasoft/hyprviz
    - Another GUI config editor for Hyprland
- https://github.com/olafkfreund/r-hyprconfig
    - TUI (ratatui) for editing Hyprland config, written in Rust
