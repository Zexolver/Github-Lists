## A list of Hyprland Utilities

- https://github.com/psi4j/sunsetr
    - Blue-light/gamma adjustment daemon for Hyprland, written in Rust
- https://github.com/ry2x/hyprcrop
    - Screenshot cropping tool for Hyprland
- https://github.com/t4t5/hypruler
    - Helper to grab window class/title for writing windowrulev2 rules
- https://github.com/maravexa/hyprsaver
    - Save/restore window layouts & sessions for Hyprland
- https://github.com/nouritsu/hyprzoom
    - Zoom into windows/screen on Hyprland
- https://github.com/ry2x/HyprBind
    - Keybind cheatsheet/viewer for Hyprland
- https://github.com/meowrch/HotKeyHub
    - Another keybind hub/cheatsheet tool
- https://github.com/FieldofClay/hyprland-workspaces
    - Workspace indicator widget/module for Hyprland
