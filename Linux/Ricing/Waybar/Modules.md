## A list of Waybar Modules (written in Rust)

- https://github.com/cybergaz/waybar-now-playing
    - Waybar module showing current track info
- https://github.com/stefur/lizzy
    - Waybar module for media playback using DBus signals
- https://github.com/bjesus/wttrbar
    - Waybar module for weather via wttr.in
- https://github.com/mryll/printbar
    - Waybar module for printer status, supply levels, and jobs (IPP/SNMP/CUPS)
- https://github.com/mryll/meteobar
    - Waybar module for weather via Open-Meteo, no API key required

- https://github.com/mryll/tickerbar
    - A multi-market price ticker for Waybar - crypto, stocks, indices and forex in one module, no API key. Omarchy theming, AUR.
