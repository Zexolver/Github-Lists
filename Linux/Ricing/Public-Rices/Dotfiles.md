## Public Rices / Personal Dotfiles
#### Individual people's personal desktop configs, not general-purpose tools.

- https://github.com/knightfallxz/Hyprland-Custom-Configuration
    - Personal dotfiles for Hyprland, Waybar, Fish, and Tmux
- https://github.com/Mccalabrese/Genoa
    - A battery-optimized, multi-compositor (Niri, GNOME, Sway) Arch Linux setup with custom Rust CLIs for Waybar, wallpaper management, and power control - tuned for a ThinkPad X1 Extreme
- https://github.com/TheAhumMaitra/Aurora
    - A minimal, elegant Hyprland preconfigured rice
- https://github.com/saimoomedits/eww-widgets
    - Personal eww widget configs
- https://github.com/druskus20/eugh
    - Various personal eww configs
