## ChromeOS Shim / Recovery Boot Tools (for booting Linux on Chromebooks)

- https://github.com/xmb9/Priism
    - Portable recovery image installer/shim manager
- https://github.com/ading2210/shimboot
    - Boot a desktop Linux distribution from a Chrome OS RMA shim
- https://github.com/r58Playz/terraos
    - Boot Linux-based operating systems from an RMA shim

- https://github.com/hexdump0815/linux-mainline-on-arm-chromebooks
    - Running Linux mainline on ARM Chromebooks
