## SSH Clients, Servers, and TUI Tools (mostly Rust)

- https://github.com/joshjetson/sshing
    - An advanced ssh server management tool that is simple and easy to use
- https://github.com/TomCrypto/zssh
    - Minimal SSH server for embedded applications
- https://github.com/mkj/sunset
    - SSH for Rust, no_std and elsewhere
- https://github.com/pouriya/sssh
    - Simply connect to your ssh server
- https://github.com/w4/pisshoff
    - A fully isolated honeypot SSH server using thrussh
- https://github.com/Julien-R44/fast-ssh
    - ⌨️ FastSSH is a TUI that allows you to quickly connect to your services by navigating through your SSH config.
- https://github.com/RustCrypto/SSH
    - Pure Rust implementation of components of the Secure Shell (SSH) protocol
- https://github.com/gvariable/fssh
    - An intuitive TUI application that speeds up SSH connections with password caching and server search capabilities.
- https://github.com/JiwanChung/ggoto
    - A blazingly fast TUI for managing SSH connections with real-time server health monitoring
- https://github.com/KURANADO2/lazyssh
    - An ssh server manages TUI tools.
- https://github.com/quantumsheep/sshs
    - Terminal user interface for SSH
- https://github.com/Eugeny/russh
    - Rust SSH client & server library
- https://github.com/Termix-SSH/Termix
    - Self-hosted SSH and remote desktop management.
- https://github.com/huashengdun/webssh
    - :seedling: Web based ssh client
- https://github.com/funnyboy-roks/wannabe-ssh
    - Allow one to run pre-defined commands on a computer from a web browser
- https://github.com/vdeville/ssh-login-alert-telegram
    - Recieive telegram notfications when user connect to a server
- https://github.com/yrutschle/sslh
    - Applicative Protocol Multiplexer (e.g. share SSH and HTTPS on the same port)

- https://github.com/nasa42/webterm
    - Securely access a server's terminal even when it's behind firewalls

- https://github.com/ekzhang/sshx
    - Fast, collaborative live terminal sharing over the web

- https://github.com/veeso/termscp
    - A feature rich terminal UI file transfer and explorer with support for SCP/SFTP/FTP/S3/SMB/WebDAV

- https://github.com/TysonLabs/lazyide
    - A full IDE experience anywhere you have a terminal - SSH into a server, run lazyide, pair with your agentic coding tool
