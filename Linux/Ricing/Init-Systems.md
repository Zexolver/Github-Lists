## Init Systems / Service Supervisors (mostly Rust)

- https://github.com/yonasBSD/zinit
    - An init replacement that feels like runit, written in Rust
- https://github.com/rinit-org/rinit
    - Next-gen init and service-manager written in Rust
- https://github.com/hen6003/iodine
    - Init system written in Rust
- https://github.com/RGafiyatullin/broom
    - A minimal init-process
- https://github.com/gblach/definite-control
    - Linux init + services supervisor
- https://github.com/sisungo/airup
    - Modern, portable and fast implementation of service supervisor and the init daemon
- https://github.com/FedericoPonzi/Horust
    - Supervisor / init system written in Rust, designed to run inside containers
- https://github.com/iliketwertles/twinit
    - WIP init system for Linux
- https://github.com/mesalock-linux/minit
    - An init utility purely written in Rust
- https://github.com/maxking/getup
    - A simple init system for Linux
- https://github.com/tyler569/rsinit
    - A Linux init system in Rust

- https://github.com/threefoldtech/zos_init_client
    - A Rust client library for interacting with the Zinit service manager

- https://github.com/rgwood/systemctl-tui
    - A fast, simple TUI for interacting with systemd services and their logs

- https://github.com/snoyberg/pid1-rust-poc
    - No description available - likely a PID 1 / init system proof-of-concept
- https://github.com/ente76/systemd.rs
    - No description available - a systemd-adjacent Rust project
