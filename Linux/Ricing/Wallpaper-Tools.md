## A list of Wallpaper Tools for Wayland/Hyprland

- https://github.com/gitfudge0/walt
    - Wallpaper manager for Hyprland (TUI + GUI), written in Rust
- https://github.com/Aromatic05/we-layerd
    - Wallpaper engine using wlr-layer-shell
- https://github.com/nikolaizombie1/waytrogen
    - Wallpaper setter for Wayland (nitrogen-style), GUI
