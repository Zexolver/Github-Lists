## Windows Wallpaper Tools

- https://github.com/SegoCode/AutoWall
    - Live wallpapers on Windows 7/8/10/11 using an open-source wallpaper engine
- https://github.com/Miosp/city_grow_lively
    - A port of the City Grow animation for the Lively Wallpaper app on Windows
- https://github.com/rocksdanister/lively
    - Free and open-source software that allows users to set animated desktop wallpapers and screensavers, powered by WinUI 3
