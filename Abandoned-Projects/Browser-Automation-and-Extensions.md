## Browser Automation Tools & Extension Clients

- https://github.com/elde-n/tridactyl-native
    - An unofficial native client for the tridactyl web-browser extension
- https://github.com/tzervas/webpuppet-rs
    - Self-hosted browser automation
- https://github.com/notTamion/web-runnables
    - Run local commands from your browser
- https://github.com/Jason5Lee/rslide
    - A web service that lets you move through multiple HTML pages in the browser like a slide, without focusing on the app or browser (Windows only)
