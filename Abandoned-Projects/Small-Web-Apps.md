## Small Standalone Web-App Utilities/Demos

- https://github.com/kllarena07/qzgen
    - Easy QR code generator via the web browser
- https://github.com/aki-akaguma/webapp-broinfo
    - A webapp that provides browser information and hardware information
- https://github.com/ThomasHabets/livecount
    - A widget for a web page showing how many people (browsers) currently have the page open
- https://github.com/billypearce/rust-web-chat
    - A basic browser-based chat app, written in Rust using the Axum framework
- https://github.com/text-yoga/ask
    - WIP browser-based LLM question/answering for the web
- https://github.com/mineichen/llm-web-chat
    - Showcase of ollama usage within a browser
- https://github.com/oza6ut0ne/rattice
    - A media viewer for web browsers, written in Rust
- https://github.com/0xwonj/websh
    - A verifiable personal archive built on a browser-native virtual filesystem

- https://github.com/saku-koodari/web-pc
    - PC inside a web browser
- https://github.com/Terrazzo-Web/Terminal
    - A web terminal built with Terrazzo
