## WASM/Graphics Tech Demos (Rust-in-browser learning projects)

- https://github.com/PhoenixFlame101/wasm-webgl-viewer
    - Toy viewer to run Rust graphics programs in the browser using WASM
- https://github.com/joinemm/rust-wasm-webgl
    - Using Rust compiled into WebAssembly to run 3D graphics in the browser
- https://github.com/JakubSokolowski/aoc-web
    - Advent of Code solutions, run in the browser with WASM
- https://github.com/clejacquet/rust-wgpu-raytracing
    - Prototype ray-tracer implementation with WebGPU in web browsers, using Rust and WGPU
- https://github.com/shaunbennett/lucis-web
    - Raytracing in your web browser
- https://github.com/46ki75/web-image-converter
    - Convert images directly in the browser using WebAssembly - no server or Node.js required
- https://github.com/w-henderson/WebPL
    - A Prolog interpreter for the browser
- https://github.com/NicholasDrian/web_cad
    - A CAD engine targeting modern browsers
