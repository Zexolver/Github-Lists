## Cryptocurrency Wallets & Mining Software

- https://github.com/CryptoGraphics/VerthashMiner
    - GPU miner for the Verthash algorithm
- https://github.com/vertiond/verthash-one-click-miner
    - Open source Vertcoin one-click miner and Dogecoin wallet
- https://github.com/Ragnaroek/mithril
    - Pure Rust Monero miner
- https://github.com/cake-tech/cake_wallet
    - Cake Wallet - a noncustodial multi-currency wallet, and Monero.com, a noncustodial Monero-only wallet
- https://github.com/Rabbit-Company/CryptoBal-Desktop
    - Desktop application for monitoring your crypto assets
- https://github.com/novasamatech/parity-signer
    - Air-gapped crypto wallet

- https://github.com/cypherstack/stack_wallet
    - Stack Wallet - a noncustodial multicoin cryptocurrency wallet
- https://github.com/regolith-labs/ore
    - Hard Money for the Digital Age (ORE cryptocurrency)
- https://github.com/regolith-labs/ore-cli-legacy
    - Command line interface for ORE cryptocurrency mining
- https://github.com/gupax-io/gupax
    - GUI uniting P2Pool and XMRig
- https://github.com/crabby-ai/les
    - An open source Rust high performance cryptocurrency trading API with support for multiple exchanges

- https://github.com/gear-tech/gear
    - Web3 Ultimate Execution Engine (blockchain)
