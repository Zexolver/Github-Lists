## OS/Kernel Dev Tutorials & Practice Repos (Rust)
#### Learning exercises, not real usable kernel projects - see the other files in this folder for those.

- https://github.com/phip1611/rust-kernel-x86_64-static-link-code-model-kernel
    - Minimal example showing how to build a statically-linked, non-relocatable Rust kernel
- https://github.com/chyyuu/os_kernel_lab
    - OS kernel labs based on Rust/C, RISC-V 64/x86-32
- https://github.com/mdaverde/kernel-modules-rust
    - Linux kernel modules written in Rust
- https://github.com/d0u9/Linux-Device-Driver-Rust
    - Following the Rust port for Linux kernel driver development
- https://github.com/m00nwtchr/oc2_hello_world
    - Open Computers II (RISC-V Musl Linux) Hello World Rust example, made very small

- https://github.com/flosse/rust-os-comparison
    - A comparison of operating systems written in Rust
