## General-Purpose Rust Libraries (no specific application domain)

- https://github.com/tokio-rs/tokio
    - A runtime for writing reliable asynchronous applications with Rust - I/O, networking, scheduling, timers
- https://github.com/slawlor/ractor
    - Rust actor framework
- https://github.com/zargony/fuse-rs
    - Rust library for filesystems in userspace (FUSE)
- https://github.com/cberner/fuser
    - Filesystem in Userspace (FUSE) for Rust
- https://github.com/d-e-s-o/uid
    - A crate for the creation of unique IDs

- https://github.com/baoyachi/shadow-rs
    - Build-time information stored in your Rust project (binary/lib/cdylib/dylib/wasm)
- https://github.com/grpc/grpc-rust
    - A native gRPC client & server implementation with async/await support
- https://github.com/Totodore/socketioxide
    - A socket.io server implementation in Rust, integrates with the Tower ecosystem and the Tokio stack
- https://github.com/orion-rs/orion
    - Usable, easy and safe pure-Rust crypto library

- https://github.com/vosen/ZLUDA
    - CUDA on non-NVIDIA GPUs
- https://github.com/flipperzero-rs/flipperzero-rs
    - Rust on the Flipper Zero
- https://github.com/turnage/valora
    - Painting by functions - a generative art library
- https://github.com/larksuite/rsmpeg
    - A Rust crate that exposes FFmpeg's power as much as possible
- https://github.com/Hans-Halverson/brimstone
    - A new JavaScript engine written in Rust
- https://github.com/aurae-runtime/aurae
    - Distributed systems runtime daemon written in Rust
