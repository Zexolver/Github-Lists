## Roblox Linux Clients/Runtimes (e.g. Sober)

- https://github.com/vinegarhq/sober
    - Runtime for running Roblox on Linux
- https://github.com/equinoxhq/equinox
    - A runtime for Roblox on Linux using containers
    - Alternative to Sober
- https://github.com/Mahatur/RobloxSoberRamdisk
    - Ramdisk setup for Sober
- https://github.com/Nightro-Fx/Performance-FastFlags
    - FastFlags tweaks for improving Sober (Roblox on Linux) performance
