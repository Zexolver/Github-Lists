## Self-Hosted Cloud Storage / File Hosting Servers

- https://github.com/nextcloud/server
    - Nextcloud server - a safe home for all your data
- https://github.com/budde25/nxcloud
    - A CLI client to interact with NextCloud
- https://github.com/Trioxidation/Triox
    - A free file hosting server that focuses on speed, reliability and security
- https://github.com/AtalayaLabs/OxiCloud
    - Ultra-fast, secure & lightweight self-hosted cloud storage - files, photos, calendars & contacts, built in Rust

- https://github.com/stalwartlabs/stalwart
    - All-in-one Mail & Collaboration server - secure, scalable, fluent in every protocol (IMAP, JMAP, SMTP, CalDAV, CardDAV, WebDAV)
- https://github.com/dani-garcia/vaultwarden
    - Unofficial Bitwarden-compatible server written in Rust (formerly bitwarden_rs)
- https://github.com/Dominux/Pentaract
    - Unlimited file cloud storage, based on using the Telegram API
- https://github.com/datenlord/datenlord
    - DatenLord - Computing Defined Storage, an application-oriented, cloud-native distributed storage system
- https://github.com/QuakeWang/storify
    - An object storage utility written in Rust
- https://github.com/CurvineIO/curvine
    - AI-Native & Cloud-Native FS - a high-performance file semantic layer for cloud object storage with high-speed cache
- https://github.com/apache/opendal
    - Apache OpenDAL: One Layer, All Storage
- https://github.com/apache/opendal-ofs
    - A userspace filesystem backed by Apache OpenDAL
- https://github.com/AlistGo/alist
    - A file list/WebDAV program that supports multiple storage backends
- https://github.com/harababurel/gcsf
    - A FUSE filesystem based on Google Drive

- https://github.com/toshi-search/Toshi
    - A full-text search engine in Rust
- https://github.com/voctal/epsilon
    - An open-source search engine made in Rust
- https://github.com/kanidm/kanidm
    - Kanidm - a simple, secure, and fast identity management platform
- https://github.com/owntracks/quicksetup
    - A mostly-automated installer for OwnTracks Recorder, Frontend, MQTT and Let's Encrypt
