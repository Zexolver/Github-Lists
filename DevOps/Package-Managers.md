## Cross-Distro / Alternative Package Managers

- https://github.com/pacstall/pacstall
    - An AUR-inspired package manager for Ubuntu
- https://github.com/Juanperias/run-it
    - A new-gen package manager, written in Rust
- https://github.com/ripytide/metapac
    - Multi-backend declarative package manager
- https://github.com/steven-omaha/pacdef
    - Multi-backend declarative package manager for Linux

- https://github.com/pop-os/debrepbuild
    - A project for automatically generating and maintaining Debian repositories from a TOML spec
- https://github.com/Charlie-117/ezdeb
    - A CLI application that helps users manage Debian packages from 3rd party websites and GitHub repositories

- https://github.com/wimpysworld/deb-get
    - apt-get for .debs published via GitHub or direct download
- https://github.com/DevilxKiller/package-repository-server
    - Host a multi-format package repository server for DEB, RPM, Arch, and Alpine packages with automatic indexing and GPG signing
- https://github.com/brandonio21/cargo-makepkg
    - Build Arch Linux packages from cargo

- https://github.com/velvet-os/imagebuilder
    - A simple script framework to build Debian bootable USB/SD card images for ARM and Intel devices
- https://github.com/PJ-Singh-001/Cubic
    - Custom Ubuntu ISO Creator
