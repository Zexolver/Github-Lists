## Server/Remote Monitoring Dashboards & Homelab-ish Tools

- https://github.com/nickprotop/ServerHub
    - A TUI server monitoring and management dashboard for Linux - real-time metrics, logs, and remote control from your terminal
- https://github.com/rhellstrom/resource-monitor
    - A Rust-based lightweight server monitoring tool
- https://github.com/TUI-Sushi/Monitor
    - TUI to monitor remote server performance without installing serverside software
- https://github.com/mapfumo/bacnet-gateway
    - Unified IIoT monitoring platform combining LoRaWAN, Modbus TCP, and BACnet/IP sensor data into Grafana dashboards - embedded Rust firmware for STM32/W5500 Ethernet, InfluxDB 2, Docker Compose infrastructure
- https://github.com/mhajder/tftp-rs
    - A high-performance, single-binary TFTP server with a real-time TUI dashboard, implementing the TFTP protocol from scratch

- https://github.com/quasiL/tuixel
    - TUIxel - a terminal UI for server management
- https://github.com/uzairali19/orkesy
    - Runtime-agnostic TUI for managing services, logs, commands, and metrics
- https://github.com/Dark-Alex-17/managarr
    - A TUI and CLI for managing *arr media servers (Sonarr/Radarr/etc)

- https://github.com/KevKibe/Automated-Serverless-App-Uptime-Maintenance-with-Rust-and-GitHub-Actions
    - A script to keep an app on a free-tier serverless platform alive (pings it every 5 minutes)
- https://github.com/defenxor/dsiem-rs
    - Dsiem (Security Information and Event Management) in Rust
