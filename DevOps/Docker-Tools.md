## Docker Tools (TUIs, monitors, firewalls, portable runtimes)

- https://github.com/knockshore/dockerportable
    - A portable Docker VM using QEMU for Windows - no admin privileges and no installations
- https://github.com/uniras/Portable-Docker-for-Windows
    - A portable Docker setup for Windows, no installation required
- https://github.com/tmknight/docker-autoheal
    - Monitor and remediate unhealthy Docker containers
- https://github.com/pitkley/dfw
    - Docker Firewall Framework, written in Rust
- https://github.com/softprops/shiplift
    - Rust interface for maneuvering Docker containers
- https://github.com/robertpsoane/ducker
    - A Docker TUI based on k9s
- https://github.com/amir20/dtop
    - Terminal dashboard for Docker monitoring across multiple hosts, with Dozzle integration
- https://github.com/mrjackwills/oxker
    - A simple TUI to view & control Docker containers

- https://github.com/youki-dev/youki
    - A container runtime written in Rust
- https://github.com/GhostKellz/nova
    - Wayland-Native Virtualization & Container Manager - bare metal speed, declarative control, GPU-first

- https://github.com/ovexro/dockpanel
    - Modern server management panel - sites, databases, Docker apps, Git deploy, mail, DNS, monitoring, backups, and security in one panel
- https://github.com/Velooroo/Flare
    - A lightweight toolchain for deploying applications to edge devices, replacing Ansible/Docker with a single-binary daemon
- https://github.com/bethropolis/podbox
    - Declarative Podman containers with Wayland/GPU/audio passthrough, XDG dir sharing, and GUI app export
