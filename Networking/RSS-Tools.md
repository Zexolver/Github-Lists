## RSS/Feed Tools

- https://github.com/wezm/rsspls
    - Generate RSS feeds from websites
- https://github.com/feed-rs/feed-rs
    - A simple feed parser (RSS, Atom, JSON Feed)
- https://github.com/XertroV/discourse-rss-auto-archive-linked-content
    - A Rust service that monitors a Discourse forum's RSS feed and archives links to ephemeral user-generated content
