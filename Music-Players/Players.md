## Music Players (mostly Rust)

- https://github.com/wiremann/wiremann
    - A fast, no-nonsense music player built in Rust. Just pure, native speed.
- https://github.com/Neixen911/miMusic
    - miMusic, a self-hosted audio player designed for lightweight systems. Performance based. Include a free song downloader.
- https://github.com/notryanb/music-player
    - A simple GUI audio player written in Rust with egui. Inspired by foobar2000.
- https://github.com/Enn3Developer/n_music
    - Cross-platform music player written in Rust + Slint
- https://github.com/hinto-janai/festival
    - Music player
- https://github.com/SajjadHadi/Harmoniq
    - Local music player with Tauri and Vue
- https://github.com/Laefye/FurPlayer
    - YouTube Video/Music Player in Rust (Tauri)
- https://github.com/callum-jones19/coralia
    - A cross-platform local music player, written in Rust and Typescript.
- https://github.com/lpradopostigo/grass-music-player
    - desktop music player with gapless playback
- https://github.com/muzik-apps/muzik-offline
    - A cross platform, local music player
- https://github.com/xudong7/tauri-rmusic
    - A cross-platform desktop music player built with Tauri、Rust and Vue.js.
- https://github.com/basharovV/musicat
    - A sleek desktop music player and tagger for offline music 🪕. With gapless playback, smart playlists, and a map view! Built with Svelte and Tauri

- https://github.com/rezkhaleghi/pj-player
    - A Rust-based CLI tool to search, download, and stream audio directly from your terminal
    - Interface: CLI
- https://github.com/ramsayleung/rspotify
    - Spotify Web API SDK implemented in Rust (a library, not a standalone player)
- https://github.com/talwat/lowfi
    - An extremely simple lofi player

- https://github.com/sonic-liberation/spotube-plugin-spotify
    - Unofficial Spotify metadata plugin for Spotube

- https://github.com/DownMaple/music-win
    - Music software, produced using Tauri + Vue3 + TS + Vite + Pinia
- https://github.com/2gn/tatar
    - A YouTube music client made with Tauri
- https://github.com/KrisShin/musicbox
    - A simple music downloader with Tauri, supports multi-platform
