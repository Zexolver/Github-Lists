## Android ↔ Linux Integration Tools (Linux-on-Android, second-monitor-over-USB, Hyprland companions, etc.)

- https://github.com/abhay-byte/fluxlinux
    - FluxLinux is Linux on Android, advanced orchestrator application that transforms your Android device into a versatile Linux workstation.
- https://github.com/The412Banner/Bannerlator
    - Bannerlator — run Windows PC games and apps on Android (Wine + Box64/86). A personal, community-driven continuation of the discontinued Winlator Star Bionic project. GitHub Actions builds + releases.
- https://github.com/localdesktop/localdesktop.github.io
    - Local Desktop helps you run a desktop Linux environment on your Android device.
- https://github.com/Tymonoman/extraspace
    - Use an Android tablet as a real second monitor for GNOME/Wayland, over USB — with touch and camera passthrough
- https://github.com/shadow-x78/orbiscreen
    - Kernel-level virtual secondary displays for Linux (X11 & Wayland via evdi), streamed natively to Android tablets and phones over MPEG-TS/H.264.
- https://github.com/ydog12138/liteavd
    - Linux/Wayland workspace for running and controlling multiple Android Virtual Devices
- https://github.com/adiimanav/moreland
    - Turn an Android tablet into a wired second monitor for Linux/Wayland over USB - zero-copy, hardware-encoded.
- https://github.com/namikofficial/hypr-phone
    - Open-source Wayland-native Android companion for Hyprland - unifies ADB device management, wireless pairing, scrcpy screen mirroring, and rofi/wofi quick actions
