## Misc Android Utility Apps

- https://github.com/JStumpp/awesome-android
    - A curated list of awesome Android packages and resources.
- https://github.com/Arcticons-Team/Arcticons
    - A monotone line-based icon pack for android
- https://github.com/manujainz/notesy-android
    - AI-Based Notes App designed to make the note-taking experience seamless and fluid.
- https://github.com/OmniKee/OmniKee
    - A KeePass-compatible password manager for Linux, Windows, Android, and your web browser
- https://github.com/MateriiApps/OpenCord
    - An open-source Material You implementation of the Discord Android app
- https://github.com/Treecord/Treecord
    - A modded Discord client for Android
- https://github.com/rust-mobile/android-activity
    - Glue for building Rust applications on Android with NativeActivity or GameActivity
- https://github.com/Bertus-W/crates-io-android
    - An Android app for browsing crates.io (the Rust package registry)
- https://github.com/ffalt/starfield
    - An Android live wallpaper that simulates a flight into a starfield

- https://github.com/LawnchairLauncher/lawnchair
    - A customizable, open-source Android launcher
- https://github.com/samandar-me/PinterestApp
    - Pinterest clone Android app - displays images from Unsplash API, save/search favorites
- https://github.com/SamThompson/BubbleActions
    - An open source implementation of the long-press actions in the Pinterest app

- https://github.com/EFForg/apkeep
    - A command-line tool for downloading APK files from various sources

- https://github.com/maocide/UndeadWallpaper
    - Turn any video on your phone into a seamless live wallpaper

- https://github.com/BeckhamLabsLLC/LinGlide
    - Turn your phone or tablet into a wireless second monitor for Linux, zero app install
- https://github.com/Khh-vu/wifi-password-manager
    - Simple app using Shizuku or root access to manage WiFi passwords
- https://github.com/TheQmaks/justapk
    - Download any APK by package name - 6 sources, automatic fallback, Cloudflare bypass
