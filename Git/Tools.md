## Git Clients, TUIs, and Workflow Tools (mostly Rust)

- https://github.com/jlpatter/oxidized_git
    - A Git GUI written in Rust!
- https://github.com/gitui-org/gitui
    - Blazing 💥 fast terminal-ui for git written in rust 🦀
- https://github.com/GitoxideLabs/gitoxide
    - An idiomatic, lean, fast & safe pure Rust implementation of Git
- https://github.com/o2sh/onefetch
    - Command-line Git information tool
- https://github.com/nickgerace/gfold
    - CLI tool to help keep track of your Git repositories, written in Rust
- https://github.com/medwards/gitt
    - Git repository viewer for your terminal
- https://github.com/myaple/grw
    - A TUI written in rust to watch git repos in real-time.
- https://github.com/nickolaj-jepsen/fnug
    - Fnug runs all your lints, tests and commands at once, in the terminal. With git integration and file watching
- https://github.com/daniel7grant/gw
    - Watch local git repositories, keep in sync with remote and run commands.
- https://github.com/croissong/gitwatch-rs
    - CLI to watch a local git repo and automatically commit changes
- https://github.com/altsem/gitu
    - A TUI Git client inspired by Magit
- https://github.com/m1guelpf/auto-commit
    - A CLI tool that automatically writes commit messages for you.
- https://github.com/zurawiki/gptcommit
    - A git prepare-commit-msg hook for authoring commit messages with LLMs.
- https://github.com/trasta298/keifu
    - Git genealogy, untangled. A TUI for navigating commit graphs with color and clarity.
- https://github.com/MitMaro/git-interactive-rebase-tool
    - Native cross-platform full feature terminal-based sequence editor for git interactive rebase.
- https://github.com/loaden/gitauri
    - Tauri gui for git written in rust.
- https://github.com/j178/prek
    - ⚡ A fast Git hook manager written in Rust, designed as a drop-in alternative to pre-commit, reimagined.
- https://github.com/jdx/hk
    - git hooks and project lints
- https://github.com/0xN1nja/watch-my-git
    - Get notified when someone unfollows you on GitHub
- https://github.com/tidynest/gitbye
    - Notices the accounts that follow you, collect the follow-back, then quietly leave. Takes your follow back so their numbers stop counting you.
- https://github.com/MathisBurger/git-contrib-aggregator
    - A self-hosted service for aggregating all my contributions to different git servers.

- https://github.com/rhysd/git-brws
    - Command line tool to open a repository, file, commit, diff, tag, PR, blame, issue, etc. in your browser for various hosts
- https://github.com/XAMPPRocky/octocrab
    - A modern, extensible GitHub API client for Rust

- https://github.com/agavra/tuicr
    - A code review TUI with vim keybindings

- https://github.com/sirwart/ripsecrets
    - A command-line tool to prevent committing secret keys into your source code
- https://github.com/clog-tool/clog-cli
    - Generate beautiful changelogs from your Git commit history

- https://github.com/tristonarmstrong/Zlum
    - Rage - a Rust-based git UI, kind of like Gogs / cgit

- https://github.com/KannarFr/glab-desktop-ui
    - A glanceable desktop inbox for GitLab threads that need your reply
